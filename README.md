# 协同事务平台

协同事务平台为需要多机构参与的业务提供统一的机构、授权、案件、证据、审批、资源预约、资金分录、消息归并、通知、定时任务和历史回放能力。项目只使用 Python 标准库与 SQLite，适合在单个 Linux 应用容器内运行。

## 政策目标履约核算

平台内置绿色采购与中小企业预留份额的履约核算，覆盖从目标下达到年末关账的完整链路：

- **可换版目标**：每个财政年度按采购单位及货物、工程、服务分类开设目标账户；年度目标下达、换版、单位间调剂、释放与结转全部记为双边移动，任何移动在事务内校验来源余额，并发处理不会透支总目标，每次变更生成可追溯的目标版本。
- **可回放执行依据**：计划承诺、预算预留、招标结果（中标/流标）、履约进度、合同缩减、紧急采购与例外决定按账户顺序落为不可变事件，可随时回放重建承诺、预留、中标、履约、豁免五类计数与目标缺口。
- **规则按生效时间适用**：目录与比例规则只约束生效之后登记的计划，事件上记录所适用的规则版本；已发布的阶段结果不可改写，更正产生带指针的新版本。
- **权限边界**：申请例外的人不能审批自己的申请；各单位只能看本单位明细（`unit:<单位>` 作用域）；汇总岗位只能取得获授权的统计维度（`aggregate:<维度>` 作用域）。
- **回执幂等与隔离**：重复进度回执复用原处理结果；编号相同而口径不同的数据进入隔离区等待人工核定。
- **恢复接续**：`recover()` 在系统恢复后接续临近截止的整改（提醒与升级）、超过确认截止的待确认调剂（过期）与已结束年度的关账结转，全部幂等；`trace_gap` 让负责人从任一目标缺口追到相关事件、适用规则和下一名纠偏责任人。

## 目录

- `src/civicflow/`：领域服务、SQLite 持久化、权限和命令行入口。
- `tests/`：核心流程、边界条件和异常路径测试。
- `examples/`：本地演示输入。

## 配置

通过 `CIVICFLOW_DB` 指定 SQLite 文件路径；不设置时命令行使用当前目录下的 `civicflow.sqlite3`。所有时间使用带时区的 ISO 8601 字符串。

## 测试

```bash
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

## 编译或构建

```bash
PYTHONPATH=src python3 -m compileall -q src
```

## 使用

初始化数据库并运行离线演示：

```bash
PYTHONPATH=src python3 -m civicflow.cli --db /tmp/civicflow-demo.sqlite3 demo
```

运行政策目标履约核算演示（下达目标、发布规则、计划、招标、进度回执、阶段结果与缺口追溯）：

```bash
PYTHONPATH=src python3 -m civicflow.cli --db /tmp/civicflow-demo.sqlite3 demo-targets
```

查看当前案件：

```bash
PYTHONPATH=src python3 -m civicflow.cli --db /tmp/civicflow-demo.sqlite3 list-cases
```
